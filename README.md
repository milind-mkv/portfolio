# Milind Patil — Video Editor Portfolio

A high-retention, modern dark-themed portfolio crafted for video editors, motion designers, and content creators.

## ✨ Features Added & Improvements
- **Fixed 12-Column Grid**: Resolved row overflow and column span bugs (`7 + 5 = 12`, `6 + 6 = 12`, and `12` full banner).
- **Responsive Mobile Navigation**: Clean slide-in menu drawer with animated hamburger toggle.
- **Interactive Video Hover Previews**: Hovering over cards triggers muted video playback previews.
- **Category Filter Tabs**: Instant filtering by `All Projects`, `Commercial & 3D`, `Motion Graphics`, and `Long-Form`.
- **Direct WhatsApp CTAs**: Integrated WhatsApp quick buttons (`wa.me`) with pre-filled greeting text for clients.
- **Floating Contact Action**: Bottom-right WhatsApp button for fast inquiries on mobile and desktop.
- **Modal Video Player**: Dynamic modal supporting both 16:9 landscape and 9:16 vertical short-form reels.
- **Graceful Fallbacks**: Smart placeholder graphics render cleanly even before local video/thumbnail files are added.
